## 1. Executive Summary & Value Proposition

**Deadlock Protocol** is an interactive, live-action investigative demonstration mode designed to showcase the full technological depth of the **BitKaun AML Forensics Platform** during hackathon judging and field evaluations.

Activated via the terminal command `activate deadlock protocol`, the interface plunges into a cinematic, retro-cyber transition where hydraulic "blast curtains" converge into an animated biting skull emblem before launching an autonomous, real-time blockchain mempool war-room simulation.

### Why This Wins Hackathons (Judging Impact)
1. **Live Proof of ML Latency:** Proves the machine learning engine (XGBoost + Isolation Forest) can perform sub-millisecond per-transaction inference on high-velocity streaming mempool data without latency spikes.
2. **Zero Pre-Rendered Smoke & Mirrors:** Uses authentic synthetic transaction streams (`/api/stream/replay`), calculating CIOH clusters, path traversals, and feature attributions on live nodes in real time.
3. **Theatrical & Unforgettable UX:** Combines our signature CRT phosphor aesthetic, retro acoustic synthesizers, animated Three.js WebGL graphics, and cinematic skull sprites to create a dramatic demonstration.

### 3.2 Dynamic Spawning & Real-Time Flow Propagation
1. **High-Frequency Stream Ingestion:**
   - Connected to `/api/stream/replay?speed=15.0&scenario_id=peeling_0001` (or live mempool generator).
   - Every 80–150ms, a new transaction package arrives containing inputs, outputs, fee, relay IP, and propagation delay.
2. **Organic Node Materialization:**
   - If an address is already on canvas, a new directed edge connects to it with an animated glowing orb.
   - If an address is unknown, a new **Bitcoin Medallion Sprite** materializes in 3D space with a glowing particle burst and settles into the cluster via organic spring repulsion.
3. **Instant Dual-Layer ML Scoring:**
   - The transaction's 46 tabular features are extracted in under 2 milliseconds.
   - XGBoost calculates illicit probability $P(\text{illicit})$.
   - Isolation Forest calculates normalized anomaly score $S_{\text{anomaly}} \in [0, 100]$.
   - Trust color adjusts dynamically:
     - 🟢 **Green** ($P < 0.40$): Standard transaction traffic.
     - 🟠 **Orange** ($0.40 \le P \le 0.75$): Suspicious change address reuse or rapid hop.
     - 🔴 **Red** ($P > 0.75$): High-confidence illicit typology.

## 4. Architectural Implementation Blueprint

### 4.1 Frontend Component Structure
```
src/
├── components/
│   ├── deadlock/
│   │   ├── DeadlockCurtainTransition.tsx    # Blast door & animated skull chomp
│   │   ├── DeadlockSimulationEngine.tsx    # Live 3D stream controller & HUD

│   │   └── DeadlockAudioSynthesizer.ts     # Hydraulic, clack, crunch & siren Web Audio
│   └── CliOutputRenderer.tsx               # Terminal hook for 'activate deadlock protocol'
```

### 4.2 Backend Endpoints Required
- `GET /api/stream/replay`: Streams realistic transaction payloads at configurable transactions per second.
- `POST /api/deadlock/evaluate`: Lightweight sub-5ms endpoint taking raw transaction payload and returning live XGBoost + Isolation Forest attribution scores.
- `GET /api/deadlock/scenarios`: Returns pre-curated high-drama scenarios (e.g. `ransomware_heist_live`, `mixer_breakout`, `exchange_drain`).
